# H2OFlows — monorepo (archived)

This monorepo has been split into three independent repos. All active development happens there.

| Repo | Contents |
|---|---|
| [h2oflows-app/api](https://github.com/h2oflows-app/api) | Go backend, migrations, gauge adapters |
| [h2oflows-app/web](https://github.com/h2oflows-app/web) | Nuxt 4 frontend (Netlify) |
| [h2oflows-app/docs](https://github.com/h2oflows-app/docs) | Documentation site |

The `pre-split` git tag on this repo marks the last commit before the split. This repo is kept as a forensic reference — do not merge new features here.
